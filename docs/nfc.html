Browser support & this label’s quirks

Use Chrome on an NFC-equipped Android phone, enable NFC in phone settings, and open this page directly over HTTPS. An ordinary HTTP address on your laptop’s local network will not work. iPhone browsers do not offer Web NFC.

Web NFC exposes NDEF records, not raw NFC commands, chip configuration, or a full memory dump. The hex shown here contains only the record data supplied by the browser.

Our PSJ-213 dump has a Text record without the required language header. Chrome may reject it or omit part of its contents. A read error does not prove the NFC chip is faulty. If that happens, use a native NFC reader app to inspect the tag.
